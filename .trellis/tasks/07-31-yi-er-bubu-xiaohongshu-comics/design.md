# 技术设计

## 方案概览

采用“结构化内容文件 + AI 无字插画 + SVG 中文叠字 + ImageMagick 合成”的半自动流程。AI 负责创意和画面，人负责关键审核；本地工具负责尺寸、文字和最终导出，避免图像模型生成乱码。

```text
主题简报
  → 故事脚本
  → 逐页分镜
  → 逐页无字插画
  → SVG 标题/对白/旁白
  → 1080×1440 PNG
  → 一致性与发布检查
  → 小红书发布包
```

## 数据与文件契约

### 故事简报

记录栏目、读者情绪、开场钩子、治愈落点、笑点、禁用内容和页数预算。

### 脚本与分镜

脚本描述完整故事；分镜逐页记录场景、角色、动作、表情、构图、对白、旁白和连续性约束。对白不写入图像生成提示词。

### 无字插画

- 每页基于角色参考图、角色基准和该页分镜生成。
- 固定扁平暖色、深棕描边、留白充足的可爱贴纸漫画风格。
- 画面预留对白或旁白安全区；输出中不得出现可读文字、水印或签名。
- 单页失败时只重新生成该页，并再次检查前后页连续性。

### 文字叠加与导出

- 每页使用 SVG 描述标题、对白气泡、旁白卡片和页脚说明。
- 字体优先使用本机 `Noto Sans CJK SC`，并保留通用 sans-serif 回退。
- `render-page.sh` 将无字底图规范为 1080 × 1440，再把 SVG 渲染成透明 PNG 并合成最终 PNG。
- 输出文件依次命名为 `00-cover.png`、`01.png` 等，便于小红书按顺序选择。

## 角色一致性策略

1. 每次生成都提供布布和一二的代表性参考图。
2. 提示词重复稳定的形体、颜色、耳朵、斑块和腮红特征。
3. 一张图只描述必要的动作、表情与道具，避免加入无关角色。
4. 逐页生成并人工选图，不依赖一次性生成整套页面。
5. 用固定检查表比较角色身份、比例、线条、颜色和场景连续性。

## 内容安全与权利边界

- 公开成品、账号简介和发布文案不展示“粉丝同人”“非官方”“非商业”字样。
- 参考图仅作为私人非商业创作参考，不进入发布包。
- 不声称官方合作，不使用官方商标式封面，不提供商品购买引导。
- 若权利方提出删除要求，停止发布并下架相关内容；所有输出按单篇目录组织，便于移除。

## 验证方式

- `identify` 检查所有成品均为 1080 × 1440 PNG。
- OCR/人工逐字核对标题、对白和旁白，确认没有说话人姓名标签或权利状态声明。
- 逐页执行角色一致性清单和前后页连续性检查。
- 用缩略图总览检查封面吸引力、滑动节奏和文字安全区。
- 从模板复制一份测试简报，验证工作流不依赖第一篇样片的硬编码。

## 取舍

- 半自动流程比全自动多一道人工审核，但角色和文字质量更可控。
- 不训练专属模型，启动成本低且风险小；代价是跨页角色一致性需要参考图与人工挑选。
- SVG 叠字比让 AI 直接画字多一个合成步骤，但中文准确、样式可复用、修改成本低。
