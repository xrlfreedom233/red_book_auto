# 实施计划

## 1. 建立内容生产包

- [ ] 创建 `content/yi-er-bubu/` 目录和入口说明。
- [ ] 编写角色基准、内容策略、权利边界和质量检查清单。
- [ ] 写明 3 个固定栏目、5 个首批选题、试发节奏与复盘指标。

## 2. 建立可复用模板

- [ ] 创建主题简报、故事脚本、逐页分镜、图像提示词和发布文案模板。
- [ ] 创建 1080 × 1440 SVG 文字叠加模板，定义标题、对白、旁白和安全区。
- [ ] 创建 `render-page.sh`，使用 `rsvg-convert` 与 ImageMagick 合成最终 PNG。
- [ ] 验证模板可通过复制创建新篇目，且没有硬编码第一篇内容。

## 3. 完成第一篇样片内容

- [ ] 编写《睡不着的时候》主题简报、完整脚本和逐页分镜。
- [ ] 为封面及每张剧情页生成无字插画，逐页审核角色与连续性。
- [ ] 编写每页 SVG 文字叠加层并导出最终 PNG。
- [ ] 编写小红书标题、正文、标签和评论互动问题，不添加“粉丝同人”“非官方”“非商业”声明。
- [ ] 删除成图气泡中的角色姓名式说话人标签，并重新排版、渲染全部页面。

## 4. 质量验证

- [ ] 检查所有输出文件格式、尺寸、命名和页面顺序。
- [ ] 逐字核对中文内容，确保没有 AI 乱码、错字或遮挡。
- [ ] 按角色清单检查一二与布布的颜色、造型、比例和身份。
- [ ] 检查故事符合情侣代入、治愈为主、轻笑点为辅的定位。
- [ ] 检查公开成品和发布包不包含参考原图、权利状态声明、商业化表述或官方授权暗示。
- [ ] 用第二个空白主题复制模板并完成一次最小渲染，验证可复用性。

## 验证命令

```bash
find content/yi-er-bubu/episodes/001-sleepless-night/output -name '*.png' -print0 \
  | xargs -0 identify

find content/yi-er-bubu -type f -maxdepth 5 | sort
```

人工检查仍是角色一致性、中文语义、同人边界和发布体验的最终质量门。

## 风险与回滚

- 若角色跨页差异过大，只回滚并重生成失败页面，不覆盖已通过页面。
- 若 SVG 合成效果不稳定，保留无字底图与文字内容，改用其他排版工具，不重新生成插画。
- 若样片定位不符合预期，保留通用模板，只替换篇目内容与发布文案。
