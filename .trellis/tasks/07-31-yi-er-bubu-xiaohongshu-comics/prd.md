# 一二布布小红书漫画生产流程

## Goal

为喜欢一二布布、会把两个角色代入自己和对象的情侣，建立一套可重复使用的 AI 同人漫画生产流程，并完成第一篇《睡不着的时候》样片，以低成本验证“治愈陪伴 + 轻笑点”的内容方向。

## Background

- 用户没有官方授权，内容仍保持原创剧情、不冒充官方且不进行 IP 商业化；但用户明确要求公开成品、账号简介和发布文案不展示“粉丝同人”“非官方”“非商业”字样。
- 布布对应情侣中的男朋友，一二对应女朋友；重点是让已有粉丝产生“这就是我和对象”的代入感。
- 故事全部采用虚构、泛化的情侣日常，不使用用户与女朋友的真实经历。
- 用户已提供 12 张参考图：5 张布布、7 张一二，覆盖正面、全身、动作、道具和不同表情。
- 当前仓库没有既有内容系统，需要从角色基准、内容模板和第一篇样片开始搭建。

## Requirements

### 权利与发布边界

- 公开成品、账号简介和发布文案不得出现“粉丝同人”“非官方”“非商业”声明。
- 即使不展示声明，内容也不得声称或暗示官方合作、正版授权或商业授权。
- 使用原创剧情和新生成画面，不直接发布参考原图、动画截图或复刻官方故事。
- 首轮不售卖相关周边、付费内容或其他依赖 IP 授权的商品。

### 账号与内容定位

- 核心情绪价值是治愈陪伴，轻笑点用于增强节奏和记忆。
- 默认关系映射为布布对应男朋友、一二对应女朋友，但依靠互动表达关系，避免刻板性别标签。
- 固定内容栏目为：
  1. **今晚陪你**：失眠、疲惫、低落等情绪陪伴。
  2. **情侣小误会**：用反差和误解制造轻笑点，以温柔和解收尾。
  3. **两个人的小仪式**：吃饭、出门、晚安等可供情侣模仿和分享的日常仪式。
- 首批候选选题为《睡不着的时候》《生气也给你留了饭》《被子到底是谁抢的》《最后一口留给谁》《下雨天只有一把伞》。

### 单篇内容规格

- 采用小红书竖版多图滑动漫画，每张输出为 1080 × 1440 PNG。
- 单篇包含 1 张封面和 4–6 张剧情页，每页一到两个清晰画面。
- 前两页建立情境和钩子，中段推进互动，最后一页以治愈落点或轻笑点收尾。
- 每篇同时生成标题、正文、标签建议和评论互动问题，不附加权利状态声明。
- 成图对话框不显示“一二”“布布”等说话人标签，通过气泡位置、角色动作和上下文区分说话者；对白正文中自然称呼对方不受此限制。

### AI 生产流程

- 流程覆盖：主题简报 → 故事脚本 → 分页分镜 → 无字画面生成 → 中文文字排版 → 质量检查 → 发布包装。
- 建立可复用的角色资料、故事模板、分镜模板、画面提示词模板、文字叠加模板和检查清单。
- 每一步必须有明确输入、输出和人工审核点，支持只重做失败的单页。
- AI 只生成无字画面；最终中文对白、旁白和标题通过本地排版工具加入。
- 第一篇流程样片采用《睡不着的时候》：一二失眠，布布陪她聊天、数羊和递热饮；一二安心睡着后，布布却还在认真数羊。

### 角色一致性

- 布布：棕色小熊，圆方形大头、棕色圆耳、深棕轮廓与五官、浅黄色圆形腮红、短小四肢。
- 一二：白色熊猫形象，白色圆润身体、深棕耳朵及不规则头部斑块、深棕轮廓与五官、粉色圆形腮红、短小四肢。
- 参考图中的文字、服装、道具和其他角色不视为固定造型。
- 每张图检查角色身份、主色、耳朵、斑块、腮红、四肢比例、线条风格和场景连续性。

## Acceptance Criteria

- [ ] 形成角色基准、内容策略和完整工作流文档。
- [ ] 提供 3 个固定栏目及至少 5 个首批选题。
- [ ] 提供可复用的故事、分镜、提示词、文字排版和发布模板。
- [ ] 《睡不着的时候》拥有完整脚本、逐页分镜和发布文案。
- [ ] 样片输出 1 张封面及 4–6 张剧情页，全部为 1080 × 1440 PNG。
- [ ] 最终图片中的中文准确、清晰，不依赖图像模型生成文字。
- [ ] 一二和布布在所有样片页面中可明确辨认，并通过角色一致性清单。
- [ ] 任意单页画面或文字可独立替换，不必重做整篇漫画。
- [ ] 公开成品和发布文案不出现“粉丝同人”“非官方”“非商业”字样，也不包含商业化或官方授权暗示。
- [ ] 所有成图气泡均不显示角色姓名式说话人标签。
- [ ] 定义首轮试发节奏和复盘指标，供用户发布后人工记录。

## Out of Scope

- 自动登录或自动发布到小红书。
- 未经用户审核直接批量生成或发布内容。
- 长篇连续剧情、动画和视频版本。
- 一二布布相关商品、付费内容或其他商业化。
- 训练或微调专属图像模型。
