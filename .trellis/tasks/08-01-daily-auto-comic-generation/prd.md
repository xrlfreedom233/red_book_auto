# 每日自动生成整篇漫画

## Goal

在服务器上每天自动生成一篇一二布布情侣日常漫画，并在安全可行时保存到小红书创作中心草稿箱，减少人工生成和上传操作；最终发布必须由用户检查并手动完成。

## Background

- 现有内容包已经定义角色基准、选题方向、单篇流程、双格版式、气泡样式和质量清单。
- 文本阶段已可通过火山方舟 `Doubao-Seed-2.1-pro` 生成候选内容；画面阶段使用 `Doubao-Seedream-5.0-lite`；中文、气泡和最终 PNG 由本地 SVG 与 ImageMagick 合成。
- 当前工具只覆盖文本模型调用、已有图片编辑和单页渲染，尚未覆盖从零生图、整篇流水线、每日调度、历史去重、失败恢复与运行记录。
- 自动生成会消耗用户火山方舟账户额度。公开发布仍需要遵守既有内容和权利边界。
- 用户提供的 `https://t2.xiaohongshu.com/api/v2/collect` 请求从路径和请求特征看属于采集类接口，没有图片上传、笔记草稿或素材保存的证据，不能作为草稿保存接口实施。
- 用户提供的 `https://apm-fe.xiaohongshu.com/api/data` 请求带有 `biz-type: apm_fe` 和批量上报特征，属于前端性能/异常监控数据，没有草稿保存能力。
- 用户通过实际操作确认 `POST https://edith.xiaohongshu.com/web_api/sns/v2/note` 是发布接口；它携带登录 Cookie、动态签名和会话令牌，属于小红书创作中心私有接口。本任务不得调用、重放或模拟该接口。
- 用户曾在会话中暴露完整创作中心 Cookie 和签名。退出旧网页会话并重新登录属于建议的安全处置，但不作为实施阻塞条件；任务文档不得记录任何原始凭证值，新自动化也不得复用聊天中的凭证。

## Requirements

### 每日调度与选题

- 按 Asia/Shanghai 时区每天上午 09:00 运行一次，并允许手工补跑指定日期。
- 从现有核心栏目及扩展方向中轮换选题，结合日期、季节或节日，但不得为了追热点偏离治愈情侣日常定位。
- 保存历史主题和内容指纹，避免重复使用相同主题、核心冲突或结尾笑点。
- 同一天重复触发时必须幂等，除非显式要求重跑，不得重复消耗模型额度。

### 整篇生产

- 自动完成：主题简报、故事脚本、分页双格分镜、无字画面提示词、逐页画面生成、SVG 中文与气泡、PNG 合成、发布标题/正文/标签和文本质检。
- 每篇输出 1 张封面及 4–6 张剧情页，全部为 1080×1440 PNG。
- 新篇沿用上下双格、粗深色圆角边框、白底漫画气泡及一体式尾巴；成图不显示角色姓名式说话人标签。
- 每个阶段保存结构化输入、原始模型输出、规范化结果和错误信息，允许只重做失败阶段或失败单页。
- 生成目录按日期和稳定篇目标识组织，不覆盖历史成品。

### 安全、成本与可靠性

- 使用 Docker 封装运行环境，固定中文字体、ImageMagick、SVG 渲染器及脚本依赖；宿主机只负责 Docker、持久化目录、密钥和定时启动配置。
- API Key 仅从服务器密钥或环境配置读取，不进入日志、命令参数、生成内容或版本库；上线前必须使用已轮换的 Key。
- 为每次任务设置最大文本调用次数、最大图片调用次数、超时和有限重试；超过预算立即停止并记录原因。
- 只有暂时性网络或服务错误可自动重试；内容质量失败和额度错误不得无限重试。
- 单页失败不得删除或覆盖已通过页面；中断后可从最后一个已通过阶段恢复。
- 每次运行生成机器可读状态与人可读摘要，明确区分成功、部分失败和失败。
- 使用钉钉自定义机器人发送运行通知：成功时包含生成日期、篇目标识、草稿保存状态和待审核提示；失败时包含失败阶段、是否可恢复及人工处理建议。
- 钉钉 Webhook 与加签密钥仅从服务器密钥配置读取，不进入镜像、日志、版本库或通知正文；通知失败不得改变漫画任务的真实结果状态。

### 质量与发布边界

- 自动检查格式、尺寸、文件数量、页面顺序、必填文案和禁用表述。
- 记录角色、肢体、气泡指向、中文语义和画面连续性等需要视觉判断的检查结果；自动化无法可靠判断的项目不得伪报为已通过。
- 自动化生成状态为“待审核”的完整发布包；在确认存在合规且稳定的草稿保存路径后，可将图片与文案上传并保存到小红书创作中心草稿箱。
- 草稿保存成功不等于审核通过或发布成功；必须由用户检查草稿并手动点击发布，自动化不得触发发布、定时发布或绕过发布确认。
- 小红书登录态、Cookie、签名参数及其他账户凭证不得写入日志、镜像或版本库；凭证失效、出现验证码或风控提示时立即停止，交由用户处理。
- 若采用浏览器自动化，使用浏览器自身的会话存储并隔离持久化目录，不从网络请求中抽取或重放 Cookie、动态签名和私有发布接口。
- 使用 Playwright 驱动小红书创作中心页面：打开图文发布页、按顺序上传当天成图、填写标题/正文/标签并点击页面提供的“保存草稿”操作。
- Playwright 脚本不得定位或点击“发布”按钮；保存前后均通过页面状态验证当前操作是草稿，并在异常时截图留档后停止。
- 成品不得暗示官方合作或授权，不包含商品和付费引导，不复制参考原图或官方剧情。

## Acceptance Criteria

- [ ] 在服务器上可通过单条命令生成指定日期的一整篇漫画，并可配置为 Asia/Shanghai 时区每日执行。
- [ ] 提供服务器定时配置，使任务在 Asia/Shanghai 每天 09:00 触发，并能通过运行记录验证实际触发日期与时区。
- [ ] Docker 镜像可重复构建，重建或升级容器后历史主题、运行状态和成品仍保留在宿主持久化目录中。
- [ ] 一次成功运行输出完整内容文档、1 张封面、4–6 张剧情页、发布文案及运行报告。
- [ ] 所有成品均为 1080×1440 PNG，页面顺序稳定，中文由本地排版生成而非图片模型绘制。
- [ ] 连续两次触发同一日期时，默认不会重复调用模型或覆盖既有成品。
- [ ] 历史主题会参与去重，并能说明候选主题因何被判定为重复。
- [ ] 模拟文本 API、图片 API、单页渲染和磁盘中断时，任务会留下可恢复状态；恢复后只重跑未通过阶段。
- [ ] 每日调用次数受配置上限约束，失败重试有限且不会形成无限扣费循环。
- [ ] API Key 不出现在版本控制、日志、进程参数和测试夹具中。
- [ ] 成功、部分失败和失败三种运行结果均能触发钉钉通知；使用模拟 Webhook 可验证消息内容和签名且不访问真实群机器人。
- [ ] 自动检查结果与人工待审项明确分开，待审包不会被标记为已发布。
- [ ] 每次成功生成后，整篇状态为“待审核”；只有用户确认后才能在记录中转为“已审核”，系统本身不执行发布。
- [ ] 若启用小红书草稿保存，系统只完成素材上传、文案填写和“保存草稿”，并可验证草稿已出现；任何测试和生产路径都不能点击发布。
- [ ] Playwright 使用隔离且持久化的浏览器配置；用户完成一次交互式登录后，后续任务可复用登录态，登录失效时不会尝试绕过验证。
- [ ] 小红书接口或页面变化、登录过期、验证码和风控失败会留下可恢复状态，且不会反复尝试或误触发布。
- [ ] 安全测试证明自动化不存在“发布”按钮操作、私有发布接口重放或会话凭证日志输出。
- [ ] 使用模拟 API 的测试可在不消耗真实额度的情况下验证完整流水线。

## Out of Scope

- 自动点击发布、定时发布或绕过小红书的人机验证与风控。
- 逆向或伪造小红书私有签名协议、使用 `/api/v2/collect`、`apm-fe/api/data` 等采集或监控接口冒充草稿保存接口。
- 完全依赖自动视觉评分替代人工最终发布审核。
- 训练或微调专属角色模型。
- 一二布布相关商品、付费内容或商业化流程。
- 为本期 MVP 建设复杂的多用户 Web 管理后台。
