# 单页无字插画提示词

```text
Use case: illustration-story
Asset type: 小红书竖版漫画无字底图
Input images: 布布参考图（造型参考）；一二参考图（造型参考）
Primary request: 用上下两个横向画格表现同一页的连续节拍；上格 <铺垫动作>，下格 <回应或推进动作>
Scene/backdrop: <上下格共享的场景与连续道具；只改变分镜所需元素>
Subject: 布布是棕色小熊、黄色圆腮红、圆方大头、短肢；一二是白色熊猫、深棕耳朵和不规则头斑、粉色圆腮红、短肢
Style/medium: 暖色扁平贴纸漫画，深棕圆润描边，少阴影
Composition/framing: 1080×1440 竖版 3:4 整页，纯白外画布；上格 x=64..1016、y=72..654，下格 x=64..1016、y=726..1308，中间是 72 px 干净白色分隔。两格都是宽景横向构图，画面铺满格内，分别在 <上格位置> 和 <下格位置> 保留气泡安全区，角色头部与尾尖预定路径之间不放关键道具
Lighting/mood: <灯光与情绪>
Constraints: 身份和标志不得互换；只有两名角色；四肢正常；上下格场景、道具和角色比例连续；不复刻参考图的角色、台词、场景或具体镜头；粗深色圆角画格边框和气泡由 SVG 后期添加
Avoid: 任何可读文字、数字、标识、签名、水印、对话框、对白气泡、模型自画的画格边框、第三个角色、写实人体、复杂纹理
```

每页单独保存为 `raw/<页名>.png`；提示词与审核原因保存在篇目 `image-prompts.md`。生成时只预留气泡空间，不让模型画气泡或文字；后期在 SVG 内将每个尾尖明确指向分镜记录的说话角色。
